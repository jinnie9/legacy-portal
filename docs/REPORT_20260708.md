## 관찰 가능한 동작 불변 — 실제 검증

단위 테스트 외에 실제 앱을 재기동해 API로 직접 확인한 항목:

- `status` JSON 응답이 각 커밋 이후에도 계속 정수(`0→1→2`)로 나옴(enum 전환에도 응답 형식 불변).
- 지출 + 100만원 이상 상신 시 우선순위 자동 상향(`2→3`)이 리팩토링 후에도 동일하게 발생.
- 권한 없는 사용자의 승인 시도 → `HTTP 200` + 상태 변화 없음(조용한 무시, 레거시 동작 보존).
- 알 수 없는 action 코드(`99`) 호출 → `HTTP 200` + 상태 변화 없음(`switch`의 `case null` 처리로 NPE 방지 확인).
